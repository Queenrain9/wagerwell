# WAGERWELL

A fictional browser casino arcade with virtual coins and clickable fictional good-cause banners. Games: slots, baccarat, blackjack and European roulette.

Open `index.html` to play locally. `app.js` stores coins, game history and virtual project progress in browser localStorage. `styles.css` provides responsive layout.

No real-money deposits, withdrawals, exchange, real-world donations or cash value. Contributions only change local in-game fictional projects.

Deployment: https://wagerwell.hatchable.site (Hatchable project visibility may be personal/private until the owner changes it in Settings).
