# WAGERWELL

A fictional browser casino arcade with virtual coins and clickable fictional good-cause banners.

## Playable MVP
- Slots
- Baccarat
- Blackjack
- European roulette
- Virtual coin wallet
- Fictional good-cause banner projects
- Local transaction history and save data

Open `index.html` directly for local play. The project has no build dependencies.

## GitHub Pages
Deployment workflow: `.github/workflows/pages.yml`

Public URL after GitHub Pages is enabled with **Settings → Pages → Source: GitHub Actions**:
https://queenrain9.github.io/wagerwell/

## Product boundary
All coins, winnings, banners and good-cause projects are fictional in-game content. No real-money deposits, withdrawals, exchange, user transfers, or real-world donations.
